# VaidyaLoop Landing Page

A responsive, mobile-first landing page concept for the VaidyaLoop clinic and hospital management product.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling and interactive preview styling
- `script.js` — mobile navigation, product-view tabs, patient-summary tabs, roster-planner explanation toggle, demo slot selection, and WhatsApp contact form

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Contact form behavior
The demo request form validates the required fields and opens WhatsApp with a pre-filled message to **+91 6306028342**. The visitor reviews and sends the message manually. The form does not store or transmit information to a backend.
